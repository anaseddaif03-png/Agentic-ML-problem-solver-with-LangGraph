# Agentic-ML-problem-solver-with-LangGraph

An agentic AI system built with LangGraph that autonomously selects 
and applies the appropriate ML pipeline to solve a given problem.

## Tech Stack
- Python
- LangGraph
- LangChain
- scikit-learn / ML algorithms

## How it works
The agent receives a problem description, analyzes it, selects the 
right ML approach (classification, regression, clustering...), 
runs the pipeline, and returns results with explanation.
